# 玩法 v2：貓咪小確幸（Cat Moments）

PO 2026-10-22 的回饋：照顧只是「一直點點點」、貓沒有反應、按下去還有冷卻時間，不好玩。

## 別人怎麼做（取經）

| 遊戲 | 讓人想繼續玩的原因 | 我們能借的 |
|---|---|---|
| 《Neko Atsume 貓咪後院》 | 沒有失敗壓力；貓會自己來、**留下小禮物**；收集圖鑑；每次打開都有小驚喜 | 貓偶爾帶禮物、**收藏圖鑑**、沒有懲罰式的倒數 |
| 《Nintendogs》 | 互動**立刻有回饋**（摸了會搖尾巴）；訓練有進度；每隻狗有個性 | 點了馬上看到貓的反應；個性影響貓想要什麼 |
| 《The Sims 4 貓狗成群》 | 寵物有**自己的想要**（Wants）、個性決定行為、互動要「看對時機」 | **貓會提出要求**，滿足牠才是重點 |
| Tamagotchi（反面教材） | 數值掉了就逼你點、錯過就懲罰 | 避免：不要變成定時打卡 |

## 我們的限制（已驗證）

- 貓不能走動（`docs/research/walking-cat.md`），只有 9 段坐姿類動畫、縮放、花色。
- 面板按鈕經信箱傳到遊戲端，來回有延遲；遊戲原生的「給零食」「玩」也會計入。
- 錢可以讀、可以扣（已驗證）。

## 決定的做法

1. **貓的小要求（Wants）**：每隻在家的貓隨時有一個想要的事（餵食、陪玩、擁抱、梳毛、清貓砂），由需求高低和個性決定，持續約 2～4 遊戲小時，沒滿足也**沒有懲罰**，過期就換下一個。面板上以對話泡泡顯示，要的那個按鈕會發亮。
2. **看對時機才有大回饋（取代冷卻時間）**：
   - **沒有冷卻時間**，想按多少都可以。
   - 同一個動作連按會**遞減效果**（越按越沒用，休息一陣子恢復），所以亂點不划算。
   - 滿足牠的要求叫「**開心時刻**」：親密度加倍、需求回復加成、貓**立刻做出反應動畫**。
3. **小禮物與圖鑑（Neko Atsume 的樂趣）**：開心時刻有機會讓貓**帶禮物給 Zoi**（羽毛、毛線球、鈴鐺、魚骨頭…10 種，三個稀有度），親密度越高越容易遇到稀有的；收進**圖鑑**，同時給一點錢。圖鑑有收集進度。
4. **馬上有反應**：面板按鈕按下去，貓的動畫立刻播（不再被「遊戲正在動這隻貓」擋掉），面板也立刻回應。
5. 個性的作用：愛玩的貓常想玩、貪吃的貓常想吃、愛撒嬌的貓常想要擁抱。

## 實作範圍

| 項目 | 說明 |
|---|---|
| `data/wants.lua`、`pets/wants.lua` | 要求的種類、權重、持續時間、個性加成；產生、過期、滿足 |
| `data/care.lua` | 連按遞減（每用一次 ×1/(1+0.6n)，最低 0.2，每 20 遊戲分鐘恢復一次）、開心時刻加成 |
| `data/keepsakes.lua`、`pets/keepsakes.lua` | 10 種小禮物、稀有度、機率、圖鑑（存在 `state.album`） |
| `pets/care.lua` | 移除冷卻；遞減；開心時刻；禮物 |
| 存檔 v5 | `state.album`；寵物的 `want`、`recent` 沿用空值預設，舊存檔不受影響 |
| 面板 | 對話泡泡、發亮按鈕、禮物 toast、圖鑑分頁 |
| 介面轉接 | `Api.credit`（給錢）、玩家觸發的動畫強制播放 |

## 不做

- 小遊戲、訓練把戲（貓的動畫只有 9 段，撐不起來）。
- 讓錯過要求有懲罰（Tamagotchi 式壓力）。
